# Actividad práctica 1: Bad UI

## Consigna

Construir la peor versión posible de algo comúnmente utilizado, como una calculadora, un reproductor de música o una aplicación de mensajería. El objetivo es crear una interfaz de usuario tan mala que sea difícil de usar, confusa o frustrante para los usuarios. Funcional, pero diseñado para frustrar a los usuarios.

Inspirado en r/badUIbattles: Una comunidad de Reddit donde los usuarios comparten y votan por las peores interfaces de usuario que han encontrado. Puedes encontrar ejemplos de interfaces de usuario mal diseñadas en esta comunidad, lo que puede ayudarte a inspirarte para tu proyecto.

## Requisitos

- Una sola conversación con ChatGPT Canvas.
- Un solo archivo HTML `index.html`.
- Sin build tools, sin archivos CSS/JS separados, sin dependencias externas.

## Entregables

1. `index.html` $\rightarrow$ El artefacto, listo para abrir con doble click.
2. `prompts.md` $\rightarrow$ La secuencia de prompts en orden, con una anotación breve por prompt.
3. `README.md` $\rightarrow$ Qué es la página, quien lo construyó, qué funcionó y qué no.
